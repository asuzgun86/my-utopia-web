# My Utopia - web version (iPhone Safari / any phone)
Open https://asuzgun86.github.io/my-utopia-web/ in Safari > Share > Add to Home Screen.
Crew and guest data are NOT in this repository. Each phone loads "myutopia_data_V###.json" once per cruise
(button "Load My Utopia data file" on the login screen). Menus, Compass and specialty photos are public here.
